## 1 诊断

- AS 中医称之为「**大偻**」
- 推荐：(1) AS 诊断参照 **1984 修订纽约标准**（1C）；(2) 临床疑似但 X 线不能明确者，参照 **2009 ASAS axSpA 分类标准**（2C，含 MRI 骶髂关节炎、含 nr-axSpA 概念）

## 2 中医辨证分型（2D）

国家中医药管理局《大偻（强直性脊柱炎）中医诊疗方案》将 AS 证型分为两型，作为基本证型：

1. **肾虚督寒证**
2. **肾虚湿热证**

## 3 疾病分期（2B / 2C）

- 活动期：**BASDAI ≥ 4** 或 **ASDAS ≥ 1.3**
- 稳定期：BASDAI < 4 或 ASDAS < 1.3
- 需结合关节外表现综合判定

## 4 影像学检查（1C / 1B）

- 骨盆正位片：诊断 AS 的基本影像学检查
- CT：骨质结构优于 X 线
- MRI：骶髂关节炎主要检查手段，但假阳性率高、成本贵
- 超声：评估附着点炎和外周关节炎，**不推荐**用于中轴病变

## 5 病情评估（1C / 2D）

监测内容：病史 + ASAS-OMERACT axSpA 核心结构域集 + BASDAI/ASDAS + 实验室 + 影像学。
- 活动期：每月随访 1 次
- 稳定期：3-6 个月随访 1 次
- X 线复查间隔不少于 2 年

## 6 达标治疗（2D）

- 最终目标：临床缓解（ASDAS < 1.3）
- 替代目标：低疾病活动度（ASDAS < 2.1）
- 建议患者参与治疗决策

## 7 患者教育（1B / 1C / 2D）

- 戒烟（吸烟与 AS 放射学进展显著相关）
- 患者教育应贯穿诊疗全过程
- 鼓励参加医院组织的宣教课程

## 8 运动（1B / 2C）

推荐运动方式：
- **游泳**：改善 BASDAI 评分
- **太极拳**：降低疾病活动度和疼痛评分效果显著
- **全身姿势恢复训练**：改善功能受限
- 复合运动效果优于单一运动；有监督运动效果优于无监督

## 9 NSAIDs（1C / 1D / 2C）

- 活动性 AS 一线用药
- 病情稳定后改为按需给药
- 注意心血管和消化道风险
- 双氯芬酸和萘普生胃肠道风险较安慰剂高

## 10 csDMARDs（1C / 2C / 1C）

- 柳氮磺吡啶、甲氨蝶呤：主要用于外周关节炎；柳氮磺吡啶对中轴病变也有效
- 沙利度胺：维持缓解优于柳氮磺吡啶，但**孕妇绝对禁用**（致畸性），副作用：外周神经炎、肝功能异常、嗜睡
- 从低剂量开始逐渐加量

## 11 bDMARDs（1B / 2D / 1C / 2D）

- 优先用于 NSAIDs 治疗无效或有禁忌的活动期患者
- 持续缓解 ≥6 个月可考虑减量或延长用药间隔，**不推荐直接停药**
- 一种 bDMARDs 无效可换用另一种作用机制不同的

## 12 中西医结合治疗

### 12.1 经验方和中成药（2C）

系统评价显示以下均可提高常规西药（柳氮磺吡啶和/或 NSAIDs）治疗 AS 的效果：
- **经验方**：独活寄生汤、补肾强督方、补肾强督治尪汤、补肾强督清化汤、补阳还五汤
- **中成药**：益肾蠲痹丸、尪痹片、盘龙七片、痹祺胶囊、四妙丸

### 12.2 中药提取物（2C / 1D / 1C / 1C）

- **雷公藤多苷片**：改善 BASDAI/BASFI/ESR 效果好。⚠️ **肝脏和生殖系统毒性**，避免用于有生育要求的患者
- **正清风痛宁**（青藤碱）：效果优于单用柳氮磺吡啶，但皮疹发生率高，过敏体质慎用
- **白芍总苷胶囊**：降低西药相关的白细胞减少和肝功能异常，但易致腹泻

### 12.3 针灸疗法（2C）

以下均能改善 BASDAI/BASFI/疼痛评分及 ESR/CRP：
- **督灸**、**温针灸**、**隔药灸**、**火针**、**针刀**、**电针**

### 12.4 中医外治法（专家意见）

合理运用中医外治法能改善症状和疾病活动度，提高生活质量。

## 13 合并症的治疗

### 13.1 葡萄膜炎（1D / 2D / 2C）

约 23%-25.8% 的 AS 患者合并葡萄膜炎。
- 风湿科与眼科密切合作
- 优先用抗 TNF-α **单克隆抗体**（不是依那西普 —— 依那西普有诱发葡萄膜炎风险）
- 辨证：**柴连汤、龙胆泻肝汤**

### 13.2 炎症性肠病（1B / 1B / 1D / 2C）

AS 合并 IBD 发生率 4%-16%。
- ⚠️ **司库奇尤单抗和依奇珠单抗禁用**（可诱发或加重 IBD）
- 依那西普可能诱发肠道炎症
- 短期可用 COX-2 抑制剂（环氧化酶-2 选择性 NSAIDs）
- 优先用抗 TNF-α 单克隆抗体
- 辨证：**白头翁汤、乌梅丸**加减
- 中药灌肠：**康复新液、锡类散**（效果优于氨基水杨酸类药物）

### 13.3 骨质疏松（2D × 4）

AS 患者脊柱、股骨颈低骨密度患病率分别为 54% 和 51%。
- TNF 抑制剂可延缓骨密度降低
- 双膦酸盐有效
- 中成药：**金天格胶囊、左归丸、强骨胶囊、仙灵骨葆胶囊**
- 每年复测 1 次骨密度，每 2 年复查 1 次胸腰椎 X 片

### 13.4 心理障碍（2D）

AS 抑郁症发生率较高。
- **舒肝解郁胶囊、解郁丸**可改善汉密尔顿抑郁量表评分
- **逍遥散、柴胡疏肝散、甘麦大枣汤、九味镇心颗粒**单用或联用抗抑郁药均有效
- 必要时请心理科医师协助诊治
